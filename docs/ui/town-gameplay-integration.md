# 클릭형 마을 1차 게임 연결 (T2-C2)

## 현재 가능한 것
- 실제 게임의 `map.s1_test` 0층 (1,1) 안전 좌표에 `town.first`를 연결한다.
- 탐험 HUD에서 **마을 입장** 또는 **Z/Space**를 선택하면 장면/핫스팟 포인트 앤 클릭 화면이 열린다.
- 광장↔여관 이동, 장소별 목록 클릭, 키보드 초점, Esc/탐험으로 돌아가기로 화면을 닫을 수 있다.
- 마을 내부 선택은 **캐릭터의 격자 좌표·탐사 기록·스태미나를 변경하지 않는다**. 게임의 일반 틱/회복 루프는 계속 작동한다.
- 임시 UI 상태(어느 장면을 보고 있는지)는 새로고침 후 복원하지 않는다. 마을 입구에서 다시 열면 입장 장면부터 시작한다.

## 콘텐츠 연결
- 게임에 들어가는 마을 JSON은 `src/world/towns/first.json`이다. 현재는 **한 곳만 정적 등록**했다.
- `/town-maker.html`의 JSON 내보내기는 별도 다운로드다. **다운로드한 파일이 곧바로 배포된 게임을 바꾸지 않는다.**
- 제작 내용을 반영하려면 JSON을 검증한 뒤 코드/콘텐츠 PR에서 위 파일에 적용해야 한다. 이후 통합 등록 기능은 T2-C6에서 다룬다.
- 스키마/검증은 `src/content/town-schema.ts`를 메이커와 게임이 공유한다. 게임은 기존 `src/content/manifest.json`에 마을 JSON을 무단 추가하지 않도록 `src/world/towns/`에서 별도 참조한다.

## 아직 구현되지 않은 것
- NPC 배치에 대응하는 실제 대화·퀘스트 실행 (C3/C4)
- 메이커 출력 JSON의 자동 콘텐츠 등록 및 변경 영향/호환성 검증 (C6)
- 마을의 시설·상점·숙박/휴식 행동 (S7)
- 마을에서 별도 던전으로 들어가는 출입구의 편집/엔진 연결
- 한 게임에 여러 마을을 확장 등록하는 인터페이스

## 수용 검사
1. 게임의 시작 위치(안전 구역)에서 마을 입장 버튼 표시.
2. Z/Space·터치로 입장 → 광장→여관→광장 선택 → 나가기.
3. 마을 화면이 열린 상태에서 방향키를 눌러도 격자 좌표·스태미나가 변하지 않음.
4. 게임 기본 시간/안전 회복은 정상 진행되고 게임 저장 슬롯은 보존됨.
5. 입구가 아닌 칸에는 마을 입장 버튼이 생기지 않음.
6. 390px·320px 모바일에서 핫스팟을 클릭하거나 장소 목록으로 동일한 이동 가능.
7. 새로고침 후 기존 격자 위치를 유지하고, 마을 내부의 마지막 장면은 복원 대상이 아님.

코드가 연결된 것과 실제 브라우저 검증 통과를 구별한다. Playwright 및 사용자 실제 폰 시험 결과는 각 PR에서 기록한다.
