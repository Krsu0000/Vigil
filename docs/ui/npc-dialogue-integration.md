# T2-C3 — NPC 고정 배치·대화 첫 구현

## 구현된 범위
- `src/content/npc-schema.ts`: NPC ID/이름/표시 기호, 시작 노드/대화 노드/선택지와 다음 노드 참조 검사.
- `src/world/npcs/innkeeper.json`: 샘플 NPC 1명(여관 주인), 분기 대화 2개.
- `src/world/towns/first.json`: 여관 장면에 NPC 핫스팟 배치(`npc.innkeeper`).
- 게임 마을 UI에서 해당 NPC를 클릭하면 대화 화면이 열리고 선택지→다음 노드 또는 대화 종료가 작동.
- ESC는 대화 중에는 대화부터 닫고, 대화가 없으면 마을을 닫는다.
- 대화는 아직 **읽기 전용**이다. 퀘스트 수락·보상·영구 NPC 플래그 같은 게임 상태 변화는 C4에서 엔진 액션/저장 계약으로 구현할 때까지 만들지 않는다.
- 마을 메이커의 NPC 핫스팟 `npcId` 편집은 그대로 지원한다. 등록된 NPC 정의와의 자동 교차 검증/독립 NPC 메이커는 후속 작업이다.

## 직접 플레이 확인
1. 게임 시작 위치에서 '마을 입장' → '여관' → '여관 주인' 선택.
2. '여관에 관해 물어본다' → 설명 대화 → '다른 이야기를 나눈다' 또는 '대화를 마친다' 선택.
3. Esc는 대화만 닫고 여관 장면 유지. Esc 한 번 더 누르면 탐험 화면 복귀.
4. NPC와 여러 번 대화해도 격자 위치·시간 비용·보유 아이템/세이브가 바뀌지 않는다.
5. 모바일에서 대화문·선택지·닫기 버튼이 접근 가능한지 확인.

## 배포 규칙
NPC 정의 파일은 `src/world/npcs/`에 두며 기존 `src/content/manifest.json`은 변경하지 않는다. 새 JSON을 가져와도 자동 배포되지 않는다. 콘텐츠 등록 및 저장해야 할 이벤트/퀘스트 효과는 별도 PR에서 구현한다.
