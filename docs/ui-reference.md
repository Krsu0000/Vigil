## 적용

- 회색조/그림자·그라데이션·텍스처·이모지 없음. 글자 IBM Plex Sans KR 13px, 숫자·기호 IBM Plex Mono. 글꼴은 로컬 fontsource에서 제공한다. 숫자와 한글이 섞이면 KR 글꼴로 대체한다.
- PC 1440×900: 252px 상태 열, 중앙 지도·상황·명령·기록, 292px 우측 미니맵·격자 소지품·퀘스트·코덱스. 전투는 오른쪽 480px, 뒤에 어두운 덮개. 캐릭터/소지품 모달은 600px.
- 모바일 390×844: 이름+상태 2×2, 지역명, 지도 13×13칸/28px와 오른쪽 위 미니맵, 상황 한 줄, 방향 버튼 48px/휴식·귀환, 최근 기록 2줄, 하단 5탭. 320px에서는 칸/방향 버튼을 줄이며 터치는 최소 44px을 유지한다. 전투 시 지도 5줄/아래 시트/탭 숨김. 상자가 있으면 획득 안내 높이만큼 세로 스크롤한다.
- 지도는 플레이어를 중심에 두고 수동 스크롤은 다음 이동까지 유지한다. 미니맵은 탐사한 바닥·플레이어·점선 화면 범위만 표시한다. 전체 지도(M)는 같은 탐사 기록을 확대/스크롤한다.
- 탐험 명령은 이동·휴식·귀환. 상자 상호작용은 상황 영역에 별도로 표시한다. 상단 정지 버튼·위치별 시간 문구·거점까지 거리·조사 가능 개수는 없다. 비용 표시는 소지품의 장비 효과 확인에만 남긴다.
- 전투는 공격·방어·기술+아이템·도주. ‘방치’ 대신 ‘진행 중’. 기술의 최소 실제 동작은 강타다. 습격은 임시 ‘물리쳤다’ 대신 전투 시작/도주 시도.
- A안 안개: 밟은 바닥만 유지, 벽은 현재 시야에서만 표시. D-024의 벽 기억을 대체한다.

## 구현 범위

기준본의 예시 이름·레벨·재화·달력·시설 수치 등을 실제 기능으로 오인하게 옮기지 않는다. 현재 게임 시간은 틱, 정신력·오염도는 —, 퀘스트·코덱스는 빈 상태다. 캐릭터는 실제 체력/스태미나/장비와 강타를 표시한다. 거점은 현재 회복·소지품 정리만 연결했다. 시설 강화·방치 작업/25분·1/4/8시간 타이머·계보·복합 능력치는 해당 시스템 구현 때 연결한다.

키: 방향키/WASD 이동, Z/Space 상자, I 소지품, C 캐릭터, M 지도, R 휴식, B 귀환, Escape 설정. 모달/편집 영역/버튼의 기본 입력을 보존한다. 전투 중 지도·탭은 inert/비활성화하고 실제 엔진도 일반 행동을 거부한다.


## D-042 후속 사용자 수정

PC 상태/우측 열은220/248px, 중앙 지도가 남은 화면 높이를 차지한다. 모바일도 화면 높이에 맞춰 지도를 늘린다. 탐험 지도는 수동 스크롤 없이 이동/리사이즈에 따라 중심을 잡고, 전체 파악은 미니맵이 맡는다. 전체지도(M)만 직접 둘러볼 수 있으며 지도 스크롤바는 모두 숨긴다. 배경#202020/현재 바닥#626262/벽#c8c8c8. 원본 캔버스는 수정하지 않았다.

최근 기록은 이동 제외·현지 HH:mm·최대100개 저장/오래된 항목 자동 삭제다. 기본 체력/스태미나/정신력/오염도에 마법사만 마나를 추가한다. 값이 없는 자원은 —이며 직업 선택/마나 소비는 후속이다.
