현재 상태와 다음 작업을 기록한다. 과거 이력은 Git과 `docs/decisions.md`에서 확인한다.

## 1. 현재 상태

- **현재 단계:** S0·S1 완료. 사용자의 S2 진행·계속 진행 지시에 따라 첫 단위의 스태미나/시간/세이브 v3 위에 실시간 런타임을 연결했다. 휴식·습격·사용자 재미 확인이 남아 **S2 전체는 진행 중**이다.
- **코드:** 10초 자동 틱·기본 대기 회복·진행/정지 표시·일시정지·설정창 정지·15초 하트비트·위험지대 공백 정지·최소 이동 간격 200ms. 맵 배경 짙은 회색·벽 검정·이미 확인한 벽 유지도 보존했다.
- **저장:** SaveFile v3·v1/v2 변환을 유지했다. 새 세션 플래그·부분 틱·이동 간격은 저장하지 않는다. IndexedDB가 없어 새로고침하면 초기화된다.
- **Git:** PR #1~#10은 main에 병합됐다. 기준 main은 44b419e. PR #11은 아직 열려 있고 head는 370ca4a다. [PR #12](https://github.com/Krsu0000/Vigil/pull/12)은 이 head를 기반으로 별도 브랜치 `gpt-s2-runtime-20261014`에서 작업했다. PR 대상은 #11 브랜치이며 #11 병합 후 main으로 변경한다. main 병합은 사용자 담당이다.
- **작업 환경:** GPT 우선(D-018). 저장소 최신 문서·실제 코드를 기준으로 했다. Node 22.22.0과 검증용 Chromium 사용. 프로젝트 의존성·잠금 파일·코어 공개 인터페이스·세이브 형식은 변경하지 않았다. 새 이동 간격 필드로 콘텐츠 버전은 0.2.1이다.

## 4. 준비 상태와 제한

- 화면에서 자동 회복·일시정지·재개·설정창을 직접 확인할 수 있다. 위험지대 공백은 해당 공백을 처리하지 않고 사용자 재개를 기다린다.
- 안전 구역의 열려 있는 세션은 단조 시계의 지연분을 처리한다. 창을 닫았다 여는 정산·24시간 상한·IndexedDB·백업은 S3다.
- 위험지대는 현재 대기 회복만 있고 휴식·습격·팝업은 없다. 현재 정지 테스트는 시간·회복·난수 경로를 검사하며, 실제 습격과의 상호작용은 후속 검증이 필요하다.
- 최초 실제 폰 정상 이동은 사용자 확인을 받았다. 벽 개선 뒤 S2 진입은 사용자 지시로 수용했다. 이번 자동 회복·설정·백그라운드 복귀·간격 체감은 실제 폰 확인을 새로 받은 것으로 쓰지 않는다.
- 미해결 코드 오류 없음. S2 전체 재미·위험 완료 기준은 아직 충족하지 않았다.
