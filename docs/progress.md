## 2. 이번 제보·재현·수정

- 제보: 간헐적으로 키를 눌러도 곧장 이동하지 않고 버벅이는 느낌. 사용자의 정확한 입력 장치/기기에서 직접 측정한 제보는 아니므로 모든 지연 원인으로 단정하지 않는다.
- Chromium 재현: 150ms 간격의 방향 전환이 기존 200ms 제한으로 거부돼 위치가 그대로 남았다. 모바일 버튼은 touchStart/누르고 있는 동안 이동하지 않고 touchEnd의 click 때만 이동했다.
- `content/time-rules.json`: 기존 D-013에 따라 임시 최소 이동 간격을 100ms로 줄였다. `manifest.json`의 콘텐츠 버전은 0.2.5다. 100ms 미만 입력은 계속 거부한다.
- `ui/MapScreen.tsx`: 이동 버튼을 primary 왼쪽 pointerdown에서 처리하고 뒤따르는 포인터 click은 다시 이동시키지 않는다. Enter/Space와 보조기술의 click(detail=0)은 유지한다. 우클릭/보조 터치는 이동하지 않는다.
- 누르고 있기의 자동 반복·입력 큐·손을 뗀 뒤 예약 이동은 추가하지 않았다. 코어/세이브/시간·회복·습격·자동 저장의 구현은 바꾸지 않았다.
- `runtime/loop.test.ts`: 기존 200ms 경계 검사를 100/200/500ms로 확장했다. 회복 대기 검사도 새 간격 직전의 거부를 재현하도록 조정했다. 기존 검사 의도·거부 불변성을 유지한다.

- Pages main과 각 미리보기는 출처가 달라 저장을 공유하지 않는다. 파일/기기 간 이동은 아직 없다.
- 새 세션/긴 공백 뒤 부분 틱/회복 시간은 이월하지 않는다. 유한 보호/만료/지속 효과는 도입 시 시간순 분할이 필요하다.
- GPT에서 구현/검증했다. Claude Code로 넘길 구체적인 비교우위는 확인되지 않았다. 새 코어 구조·SaveFile 호환성 변경 없음.
