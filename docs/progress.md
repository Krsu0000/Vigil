## 1. 현재 상태

- **단계:** S0·S1 완료, S2 세 번째 단위 구현·검증 완료. 사용자 재미/위험 판정이 남아 **S2 전체는 완료되지 않았다**.
- **코드:** 전역 2초 틱·독립 회복 2초. 마지막 성공 이동 후 주기마다 대기 1, 위험지대 휴식 5 회복. 휴식은 성공 이동·최대치·습격에서 끝난다. 이동/휴식 전환은 전역 틱을 초기화하지 않는다. 위험지대 전역 틱에서 대기 2%·휴식 10% 습격을 판정한다. 미처리 습격은 닫아도 이동/시간/회복을 막는다.
- **유지:** 짙은 회색 지도·검정 벽·확인한 벽 유지·200ms 이동 간격·15초 하트비트·위험 공백 2분 정지·설정/수동 정지.
- **저장:** SaveFile v4, v1→v2→v3→v4 지원. 기존 스키마/예시를 보존하며 휴식·미처리 습격 왕복도 검사했다. IndexedDB는 없으므로 **새로고침하면 초기화된다**. 실제 전투/피해/보상/귀환은 아직 없다.
- **Git:** PR #1~#12는 main에 병합됐다. 이번 작업은 `gpt-s2-rest-ambush-20261015`의 [PR #13](https://github.com/Krsu0000/Vigil/pull/13)에 추가했다. main 기준 f187ef7, 승인 전 준비 커밋 6b1291e. main 병합은 사용자 담당이다.
- **환경:** GPT 우선(D-018), 저장소 최신 문서 기준. Node 22.22.0·Chromium 사용. D-029 구체안에 사용자 “ㅇㅋ ㄱㄱ” 승인을 받고 상태/세이브를 확장했다. 새 의존성·프로젝트 잠금 파일 변경 없음. 콘텐츠 0.2.4·맵 버전 1.

## 2. 이번 변경

- CharacterState.activity, ExpeditionState.pendingAmbush 추가. 최초 캐릭터는 waiting, 원정 null은 유지하고 최초 습격 때 필요한 객체만 만든다. 전체 원정 수명 주기는 미정이다.
- rest/start·rest/stop, ambush/resolve, 전역 틱의 시드 판정·일괄 진행의 발생 틱 중단, 회복 게이트와 최대치 휴식 종료를 연결했다.
- runtime은 Store를 구독해 미처리 습격에서 타이머를 멈춘다. 해결 후 전체 간격부터 재개하고 수동/설정 정지를 유지한다. 시작/종료·취소 콜백·단일 타이머 검사도 보존했다.
- UI는 휴식 시작/중지·현재 활동·회복량/습격 확률 안내·닫을 수 있는 팝업·재열기·탭 제목 알림을 제공한다. 팝업 열림만 React 일시 상태다.
- 물리쳤다/도주했다는 임시 미처리 해제다. 위치·자원·시간·난수를 바꾸지 않는다. 실제 전투 규칙은 S5에서 연결한다.
- v3 스키마를 보존하고 v3→v4 변환을 등록했다. 이전 실제 v3 작성 코드로 고정 예시를 만들었다. 구조/탐사/현재 콘텐츠의 위험 구역 검증을 모두 통과한 뒤 Store 상태를 교체한다.
- decisions D-029 승인·architecture·features·roadmap·game-design을 실제 결과에 맞췄다.

## 4. 사용자 확인과 제한

- 최초 Pages 실제 폰 정상 이동은 사용자 확인 완료. 벽 개선 뒤 “오키도키. S2 진행.”으로 S1 마감 수용. 이번 휴식/습격의 실제 폰 확인이나 재미 판정을 새로 받은 것으로 쓰지 않는다.
- 이전 1→2틱 회복 미관측 보고 뒤 2초 틱과 독립 회복(D-028)을 승인받았다. 당시 폰의 수치/시점이 없어 원인 확정과 규칙 변경을 구분한다.
- 이번 브라우저 모바일 크기/터치 검증은 실제 사용자 기기·백그라운드 복귀·OS 알림 검증이 아니다. 알림은 앱 안내·탭 제목뿐이다.
- 일반 인벤토리/코덱스 창은 아직 없으므로 해당 창을 열어 둔 시간 진행은 미검증이다. 설정은 정지하고 습격은 처리까지 막는 승인된 임시 동작이다.
- 창 닫기 뒤 회복·24시간 오프라인 상한·IndexedDB/백업은 S3다. S3 복원은 루프 종료→원자적 Store 복원→정산→새 루프 시작으로 연결하며 중복 정산을 검사해야 한다.
- 미해결 코드 오류 없음. 최신 Pages 배포에서 이번 휴식/습격을 새로 확인한 것으로 기록하지 않는다. 배포/실제 폰 결과는 이후 확인한다.
