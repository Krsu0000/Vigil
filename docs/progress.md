## 2. 이번 변경

- `runtime/input.ts`: PR #16의 키 연결로 복원했다. keydown은 OS 반복을 포함해 즉시 전달한다. 게임 내 반복 타이머·누른 키 우선순위·keyup/포인터 상태 추적·수명 주기 취소 처리를 제거했다.
- `MapScreen.tsx`: 화면 버튼은 기본 포인터를 누르면 한 칸 이동한다. 길게 누르기 반복/포인터 캡처를 제거하고 해제 click 중복 방지와 키보드·보조기술 click(detail=0)은 유지한다.
- 버튼 CSS와 도움말을 기존 방식으로 복원했다. 귀환의 자동 반복 객체 참조도 제거했다. 귀환 후 새로 도착한 OS 키 이벤트는 일반 입력으로 처리한다.
- PR #18의 저장 파일 교환과 PR #19의 귀환 엔진·저장·시간/회복/습격/자원 규칙은 유지한다. 콘텐츠/세이브/DB 구조·의존성 변경 없음.
- D-033을 제거된 결정으로 표시하고 D-036 및 architecture/features/roadmap을 갱신했다.

## 4. 사용자 확인·제한

- 최초 실제 폰 정상 이동, PR #16 후 연타 개선은 사용자 확인 완료다. 사용자가 PR #17 적용 후 조작감 이상을 제보해 자동 반복을 제거했다. 원복 후 실제 기기의 조작감은 아직 미확인이다.
- 최근 휴식/습격·저장/거점 정산의 실제 폰 확인 및 S2 재미/위험 평가는 미확인이다. 모바일 크기 자동 브라우저 검사는 실제 폰 검증이 아니다.
- 현재 귀환 목적지는 단일 맵의 콘텐츠 시작 칸(임시 거점)이다. 다중 맵/거점 선택, 실제 전투 중 제한, 전투 도주와 귀환의 연결을 구현했다고 기록하지 않는다.
- 최초 슬롯 복원 실패 화면의 파일 복구 UI는 없다. 손상/미래 버전 슬롯 보호는 유지한다. 백업 1개는 이후 자동 저장으로 회전하므로 영구 보관은 파일 내보내기를 사용한다.
- 폰 강제 종료/백그라운드에서 저장 완료는 미검증이며 최근 1초 변경은 유실될 수 있다. main/미리보기는 저장소를 공유하지 않지만 JSON 파일로 옮길 수 있다.
- GPT에서 구현/검증했으며 Claude Code로 넘길 필요는 확인되지 않았다.
