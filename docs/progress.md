- 별도 브랜치 `gpt-held-movement-20261015`: 사용자 승인에 따라 키보드·화면 버튼 길게 누르기를 게임 내 반복으로 처리했다(D-033). main 병합은 사용자 담당이다.

- 파일 내보내기/가져오기·즉시 귀환·야영지 보호 만료·방치 작업 완료·실제 전투는 미구현이다. 귀환 제약은 아직 결정하지 않았다.

## 2. 이번 제보·변경

- 사용자는 PR #16 후 연타 조작감의 개선을 확인했으나 길게 누를 때 지연이 남는다고 제보했다. 기존 키보드는 OS 반복 시작 지연/속도에 의존했고 화면 버튼의 자동 반복은 없었다.
- `runtime/input.ts`: 첫 누름을 즉시 시도하고 이후 콘텐츠 minimumMoveIntervalMs마다 기존 loop.move를 호출한다. OS repeat는 무시한다. 누른 입력/취소 세대만 세션에 보관하며 밀린 이동을 몰아서 처리하지 않는다.
- 복수 입력은 마지막 누른 방향을 우선하고 해제 시 아직 누른 방향을 다음 간격부터 시도한다. 손을 떼기·포인터 취소/캡처 손실·창 이탈/숨김·편집 영역 초점·다른 키 명령·정지/설정/습격·언마운트에서 입력을 해제한다. 벽/자원 부족도 반복을 해제한다. 재개/습격 해제/회복만으로 움직이지 않는다. 쿨다운 거부만 다음 주기를 기다린다.
- `ui/MapScreen.tsx`: 키보드/포인터를 같은 입력 객체에 연결하고 세션 정지 구독에서 즉시 해제한다. pointer capture와 window pointerup/cancel로 버튼 밖 해제를 받는다. primary/왼쪽 누름·포인터 click 중복 제외·Enter/Space/보조기술 단일 실행을 유지한다.
- 버튼 CSS에 한해 터치 스크롤/텍스트 선택/길게 누르기 메뉴를 막고 안내 문구를 갱신했다. 새 의존성·콘텐츠/세이브 스키마·코어 변경 없음.

## 4. 사용자 확인·제한

- 최근 휴식/습격·저장/거점 정산의 실제 폰 검증 및 S2 재미/위험 평가는 미확인으로 유지한다. 자동 브라우저의 모바일 크기/터치는 실제 폰 검증과 다르다.

- 화면 숨김은 누른 입력만 해제한다. 기존 게임 시간/안전 구역 정산/위험 공백 정책은 유지한다.
- 폰 강제 종료/백그라운드의 저장 완료는 미검증이며 최근 1초 변경은 비정상 종료로 유실될 수 있다. main과 각 미리보기는 저장을 공유하지 않는다. 기기 간 파일 이동은 아직 없다.
